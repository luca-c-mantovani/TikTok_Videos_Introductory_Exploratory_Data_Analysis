# TikTok Videos Introductory Exploratory Data Analysis

## Project Overview

The goal of this project was to create a machine learning model to classify whether a TikTok video is a claim or an opinion. In this portion of the project I conducted exploratory data analysis (EDA for short) on a the TikTok dataset. From this analysis I was able to draw several useful insights from the data which will help me create a machine learning model.

## Business Understanding 

On TikTok, users can report videos that contain claims. These claims need to be reviewed by moderators, but the sheer volume of videos presents a challenge to the moderation team. Opinions do not need to be reviewed by the moderation team, so I developing a predictive model that can determine whether a video contains a claim or offers an opinion to filter out user opinions. This will reduce the TikTok moderators' backlog of user reports and increase the speed of user moderation.
